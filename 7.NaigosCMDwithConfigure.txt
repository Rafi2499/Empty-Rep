🛡️ What is Nagios?
Nagios is an open-source system monitoring tool that acts like an all-seeing watchdog for server infrastructure. It continuously tracks server health, network traffic, memory usage, and running services so teams can catch system failures before users do.

Configure in Ubuntu--
# ------------------------------------------------------------------------------
# 🗡️ STAGE 1: DEPENDENCIES & ACCESS MANAGEMENT
# ------------------------------------------------------------------------------
sudo su                                             # 👑 Escalates to root user | Grants administrative access needed for system installs
apt update && apt install -y apache2 php            # 🧙‍♂️ Installs Apache2 & PHP | Web server hosts dashboard; PHP renders dynamic pages
apt install -y build-essential                      # 🛠️ Installs GCC compiler & build tools | Translates C source code into runnable binaries
apt install -y libgd-dev                            # 🎨 Installs GD graphics development files | Renders visual health graphs & status maps in UI
adduser -m nagios                                   # 💂 Creates system user 'nagios' with home folder | Runs monitoring engine under an isolated user
passwd nagios                                       # 🔑 Sets password for 'nagios' user | Secures account credentials
groupadd nagioscmd                                  # 🛡️ Creates security group 'nagioscmd' | Authorizes command transfers between Web UI & Core
usermod -a -G nagioscmd nagios                      # 📜 Adds 'nagios' user to 'nagioscmd' group | Lets daemon process web portal requests
usermod -a -G nagioscmd www-data                    # 📜 Adds Apache user 'www-data' to 'nagioscmd' group | Lets web server write commands to Nagios core.
# 💬 SUMMARY: Set up system users, security groups, and core OS dependencies (web server, compiler, graphics libraries).

# ------------------------------------------------------------------------------
# 📦 STAGE 2: SOURCE ARCHIVE RETRIEVAL & EXTRACTION
# ------------------------------------------------------------------------------
mkdir ~/downloads                                        # 📥 Creates 'downloads' directory | Isolates installation files in one place
cd ~/downloads                                           # 📂 Changes directory to ~/downloads | Sets working location for downloads
wget http://prdownloads.sourceforge.net/sourceforge/nagios/nagios-4.0.8.tar.gz  # 📜 Downloads Nagios Core archive | Fetches main engine source code
wget http://nagios-plugins.org/download/nagios-plugins-2.0.3.tar.gz            # 📜 Downloads Nagios Plugins archive | Fetches check scripts (ping, HTTP, disk)
tar zxvf nagios-4.0.8.tar.gz                             # 📦 Extracts Nagios Core archive | Unpacks raw code files for configuration
cd nagios-4.0.8                                          # 📂 Navigates into extracted Core folder | Sets context for build steps
# 💬 SUMMARY: Downloaded and extracted Nagios Core and Plugin source code archives into a clean workspace.

# ------------------------------------------------------------------------------
# 🛠️ STAGE 3: COMPILING & INSTALLING NAGIOS CORE
# ------------------------------------------------------------------------------
./configure --with-command-group=nagioscmd               # 🔍 Runs configuration script | Checks system setup and builds custom Makefile
make all                                                 # ⚔️ Compiles C source files | Converts raw code into machine executables
make install                                             # 🏰 Copies binaries to /usr/local/nagios/ | Places core engine files in system paths
make install-init                                        # 🔄 Installs init startup script | Allows managing Nagios as a system background service
make install-config                                      # 📜 Installs default sample configs | Provides template configuration files required to run
make install-commandmode                                 # 🔓 Sets permissions on external command folder | Secures communication between Web UI & Core
make install-webconf                                     # 🌐 Installs Apache configuration file | Routes /nagios Web UI path through Apache
htpasswd -c /usr/local/nagios/etc/htpasswd.users nagiosadmin  # 🎟️ Creates web login user 'nagiosadmin' | Restricts dashboard access to authorized admins
systemctl restart apache2                                # ⚡ Restarts Apache web server | Loads new Nagios web routes and settings
# 💬 SUMMARY: Compiled Nagios Core from source, installed binaries, deployed configs, and created Web UI admin login.

# ------------------------------------------------------------------------------
# 🔌 STAGE 4: COMPILING & INSTALLING NAGIOS PLUGINS
# ------------------------------------------------------------------------------
cd ~/downloads                                           # 📂 Returns to ~/downloads folder | Prepares to process plugin files
tar zxvf nagios-plugins-2.0.3.tar.gz                     # 📦 Extracts Nagios Plugins archive | Unpacks plugin code files
cd nagios-plugins-2.0.3                                 # 📂 Navigates into extracted Plugins folder | Sets context for plugin build steps
./configure --with-nagios-user=nagios --with-nagios-group=nagios  # 🔍 Prepares plugin build settings | Binds plugin permissions to nagios user/group
make                                                     # ⚔️ Compiles plugin source files | Builds monitoring utilities (check_ping, check_disk)
make install                                             # 🎒 Copies plugins to /usr/local/nagios/libexec/ | Places scripts where Nagios Core can run them
# 💬 SUMMARY: Compiled and installed official Nagios Plugins that perform actual health checks on servers and services.

# ------------------------------------------------------------------------------
# 🚀 STAGE 5: SYSTEM VERIFICATION & SERVICE ACTIVATION
# ------------------------------------------------------------------------------
systemctl enable nagios                                  # 🔁 Enables Nagios service on boot | Auto-starts monitoring if server reboots
/usr/local/nagios/bin/nagios -v /usr/local/nagios/etc/nagios.cfg  # 👁️ Runs syntax verification check (-v) | Catches configuration errors before startup
systemctl start nagios                                   # 🔥 Starts Nagios background service | Begins active monitoring checks
systemctl restart apache2                                # 🌐 Restarts Apache web server | Syncs web dashboard with running Nagios engine
# 💬 SUMMARY: Verified configuration syntax, enabled auto-boot, launched the Nagios service, and refreshed the web server.
