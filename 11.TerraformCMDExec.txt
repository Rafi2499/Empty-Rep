What is Terraform -> 
    Terraform is an Infrastructure as Code (IaC) tool that allows you to safely **provision** (create/build) and **manage** (update/scale/destroy) cloud infrastructure using simple configuration files.

   [ 📄 Code Blueprint ] ──► [ 🤖 Terraform ] 
                                    │
                                    ├──► 🚀 PROVISION : Builds new servers & databases
                                    │
                                    └──► ⚙️ MANAGE    : Updates, scales, or deletes them safely

------------------------------------------------------------------------------
🌐 1. ECOSYSTEM ARCHITECTURE
------------------------------------------------------------------------------

   [ 🏛️ HashiCorp Registry ] ──(Downloads Plugins/Modules)──► [ 💻 Local Environment ]
                                                                      │
                                                            (Executes `.tf` code)
                                                                      │
                                                                      ▼
   [ 🔒 terraform.tfstate ] ◄──(Syncs Real IDs & State)─── [ 🤖 Terraform CLI Engine ]
   (Tracks Infrastructure)                                           │
                                                            (Calls Cloud APIs)
                                                                      │
                                                                      ▼
                                                    [ ☁️ AWS / Azure / GCP Cloud ]
                                                    (Deploys VMs, DBs, Subnets)

------------------------------------------------------------------------------
🧱 2. THE 3 CORE BUILDING BLOCKS & SAMPLE CODE (main.tf)
------------------------------------------------------------------------------

A. PROVIDERS : Connects Terraform to Cloud APIs.
terraform {
  required_providers {
    aws = { source = "hashicorp/aws", version = "~> 5.0" }
  }
}

B. LOGIN : Authentication using AWS CLI, environment variables, or IAM keys.
provider "aws" {
  region = "us-east-1"
}

C. RESOURCES : The actual infrastructure to build.
resource "aws_instance" "web_server" {
  ami           = "ami-0c55b159cbfafe1f0" // Amazon Linux OS
  instance_type = "t2.micro"                // Server Size
  tags          = { Name = "MyServer" }
}

🗺️ 3. COMMAND EXECUTION WORKFLOW
------------------------------------------------------------------------------

   [ 📄 Code (*.tf) ] ➔ 1️⃣ init ➔ 2️⃣ validate ➔ 3️⃣ plan ➔ 4️⃣ apply ➔ 5️⃣ destroy
                           │          │            │          │           │
                           ▼          ▼            ▼          ▼           ▼
                        Download    Check       Preview     Deploy      Clean Up
                        Plugins     Syntax      Changes    Resources   Everything

1️⃣ terraform init ➔ 📥 DOWNLOAD PLUGINS
   [ 📄 Code ] ──► 🤖 [ CLI ] ──► 🔌 [ .terraform/ ]
   // 🟢 Run first! Opens toolbox & downloads dependencies.

2️⃣ terraform validate ➔ 🔍 CHECK SYNTAX
   [ 📄 Code ] ──► 🤖 [ CLI ] ──► ✅ [ Syntax OK? ]
   // 🟡 Code spell-checker. Finds typos fast.

3️⃣ terraform plan ➔ 🔮 PREVIEW CHANGES
   [ 💻 Code + 🔒 State ] ──► 🤖 [ CLI ] ──► 📊 [ 🟢+Add | 🟡~Change | 🔴-Delete ]
   // 🔵 Safe preview. Shows what will happen next.

4️⃣ terraform apply ➔ 🚀 BUILD INFRASTRUCTURE
   [ 📊 Plan ] ──► 🤖 [ CLI ] ──► ☁️ [ Cloud APIs ] ──► 🔒 [ State Updated ]
   // 🟢 Action time! Creates real resources in cloud.

5️⃣ terraform destroy ➔ 🧹 CLEAN UP & DELETE
   [ 🔒 State ] ──► 🤖 [ CLI ] ──► 🗑️ [ Wipe Cloud Resources ]
   // 🔴 The big eraser. Stops ongoing cloud bills.
